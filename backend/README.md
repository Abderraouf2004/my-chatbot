## Tech Stack

### Frontend

- React
- TypeScript
- Vite

### Backend

- Bun
- TypeScript
- Express.js

### Planned Features

- User authentication
- AI-powered conversations
- Streaming responses
- Persistent chat history
- Markdown and code highlighting
- Document uploads and RAG
